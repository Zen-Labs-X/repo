# v3.6.3

修复
移除 OTA 模块对 ssl.https 原生库的依赖，改用 curl 下载，避免部分设备加载原生库时导致进程崩溃
检查更新改为纯 curl + 字符串匹配实现，主线程不加载任何 OTA 重模块，从根源上防止 C 级崩溃闪退
下载与安装操作改用 Async 子进程隔离执行，即使子进程异常也不会影响主进程
自动检查更新默认改为关闭，避免后台静默触发崩溃

变更
暂时隐藏"检查更新"菜单入口（崩溃问题待进一步排查）
新增"手动下载地址"菜单项，指向 GitHub Releases 页面

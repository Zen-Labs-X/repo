# v0.3

Revamped architecture: custom submenus, tons of new tests, enhanced stability, and new mirroring functionality.

- Added custom submenus: create named submenus and move items into them for easy access.
- Added optional mirroring between Book view and File Manager.
- Improved compatibility with plugin-added menus and tabs, including Bookshelf.
- Untouched menus now follow upstream updates.
- Improved preset handling to preserve newly added items and update existing user presets.
- Fixed issues involving hidden or moved plugin items, missing menu destinations, and plugin removal/reinstallation.
- Disabling the plugin now restores stock menus; re-enabling restores custom layout.
- Expanded compatibility and regression tests.

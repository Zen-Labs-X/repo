# v1.2.0

# Pinyin IME v1.2.0

本次更新让拼音输入更灵活，并带来更丰富的词库。

## 更新

- 全拼现在支持完整拼音与声母混合输入。例如，输入 `beijdax` 即可获得“北京大学”等候选。
- 扩充常用词和专业词汇，更多此前没有结果的拼音现在可以直接找到候选。
- 优化候选查询路径，在增加新输入方式的同时，保持原有全拼、简拼和五种双拼的输入习惯。
- 保留输入方案、个性化学习和后续词联想设置，升级后无需重新设置。

## 安装

1. 下载并解压 `pinyinime.koplugin-v1.2.0.zip`。
2. 将顶层 `pinyinime.koplugin/` 完整替换到 `koreader/plugins/`。
3. 完整退出并重新启动 KOReader。
4. 进入 `设置 → 设备 → 键盘 → 拼音输入法`，确认版本为 `v1.2.0`。

最低支持 KOReader v2025.10；v2025.10、v2026.03 与 v2026.07 已正式验证。

- [完整版本说明](https://github.com/Merpyzf/pinyinime.koplugin/blob/main/versions/v1.2.0.md)
- [安装与使用说明](https://github.com/Merpyzf/pinyinime.koplugin/blob/main/README.md)
- [故障反馈说明](https://github.com/Merpyzf/pinyinime.koplugin/blob/main/SUPPORT.md)

# v1.1.1

# Pinyin IME v1.1.1

此更新带来更流畅、更稳定的输入体验，建议所有用户安装。

## 更新

- 提升长时使用后的响应速度和内存表现。
- 改进长篇内容末尾的连续输入，保持稳定响应。
- 优化个人词频学习数据的保存，减少学习记录较多时的偶发卡顿。
- 提升与 KOReader MultiUser 的兼容性，避免插件重复加载。
- 保留现有输入方案、候选偏好和个人学习数据，升级后无需重新设置。

4. 进入 `设置 → 设备 → 键盘 → 拼音输入法`，确认版本为 `v1.1.1`。

最低支持 KOReader v2025.10；v2025.10、v2026.03 与 v2026.07 已正式验证。macOS 模拟门禁的详细性能数据见完整版本说明，不作为 Oasis 1/2 真机性能结论。

# Pinyin IME v1.1.0

本版本将原“常用双拼”按标准方案名称显示为“自然码双拼”，并正式验证 KOReader v2026.07。

- 菜单、状态页和方案数据统一显示“自然码双拼”。
- 保留内部方案标识 `common` 与原有键位，旧设置无需迁移。
- 全量校验自然码键位和零声母规则；`zirjma` 的首选候选为“自然码”。
- 将 KOReader v2026.07 加入固定验证版本表。
- 全拼、其他双拼方案、词库、个性化学习和后续词联想保持不变。

1. 下载并解压 `pinyinime.koplugin-v1.1.0.zip`。
2. 将顶层 `pinyinime.koplugin/` 复制到 `koreader/plugins/`。
3. 重启 KOReader，并启用简体中文键盘。
4. 进入 `设置 → 设备 → 键盘 → 拼音输入法`，确认版本为 `v1.1.0`。

最低支持 KOReader v2025.10；v2025.10、v2026.03 与 v2026.07 已正式验证。

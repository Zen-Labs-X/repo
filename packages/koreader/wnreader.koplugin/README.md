# Web Novel Reader Plugin for KOReader

A plugin for KOReader that allows you to read web novels directly within the app.

## Features

- Browse and search popular web novel sources
- Download chapters for offline reading
- Bookmark and manage your favorite novels

## Installation

1. Copy the `wnreader.koplugin` folder to `koreader/plugins/`.
2. Restart KOReader.
3. Access the plugin from the KOReader plugins menu.

## Usage

1. Open the plugin from the plugins menu.
2. Search for a web novel or browse sources.
3. Select a novel and download chapters.
4. Start reading!

## Requirements

- KOReader 2022.01 or newer
- Internet connection for downloading chapters

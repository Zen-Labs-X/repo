## What's New in v2.1.0 🎉

### Persistent Popup Feature
The mokuro popup now stays open after dictionary lookup! This allows you to:
- Look up **multiple words** in the same speech bubble without retapping
- Study more efficiently - no need to close and reopen the popup for each word
- Works just like footnotes: popup stays underneath while dictionary opens on top
- Simply tap outside the popup when you're done

### How it Works
1. Tap a speech bubble → mokuro popup appears
2. Select a word → dictionary opens **on top** of the popup
3. Close the dictionary → **popup is still there!**
4. Select another word → repeat as needed
5. Tap outside to close the popup

This makes studying Japanese manga much more efficient! 📚

### Requirements
- KOReader v2025.08 or higher

### Installation
Download `mokuroreader-v2.1.0-standard.zip` below, extract, and copy to your KOReader plugins folder.

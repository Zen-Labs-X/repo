# 1.1

Added pathfinding algorithm:
- Click on an empty square and the player will go there
- Click on a crate and an empty square, and the player will push the crate there

Those moves will be realized only if they are possible without moving other crates.

This will speed up the play on the touchscreen devices especially for larger levels.

This release also adds support for external keyboard.

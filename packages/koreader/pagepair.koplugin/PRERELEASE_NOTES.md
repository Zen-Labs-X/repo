# v1.0.0-beta.1

## PagePair v1.0.0-beta.1

First public beta of PagePair.

PagePair is a KOReader plugin for synchronizing page turns between two Kindles, allowing them to be used together as a two-page reading setup.

### Features

- Controller and Follower roles
- Secure one-time Kindle pairing with matching verification codes
- Home Wi-Fi page synchronization
- Direct Kindle-to-Kindle Travel Mode without a router
- Persistent pairing between connection modes
- Home Wi-Fi setup and connection testing

### Compatibility

Currently tested on Kindle Basic 10th generation devices.

Other Kindle models may work but have not yet been validated.

### Installation

1. Download `pagepair-v1.0.0-beta.1.zip` below.
2. Extract `pagepair.koplugin` into `koreader/plugins/`.
3. Restart KOReader.
4. Install PagePair on both Kindles and follow the pairing instructions.

Please report bugs and compatibility results through GitHub Issues.

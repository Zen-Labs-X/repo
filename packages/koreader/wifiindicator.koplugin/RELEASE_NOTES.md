# v1.0.0

First release.

Quiet Wi-Fi status for KOReader: suppresses the Wi-Fi lifecycle popups, shows a transient corner toast and a tappable status icon in the menu bar, and connects to Wi-Fi in the background without freezing the UI (Kobo & other wpa_supplicant devices, and Kindle). Every behavior toggles individually under **Menu → Network → Wi-Fi status icon**.

### Install
Download `wifiindicator.koplugin.zip` below and unzip it — it expands to a correctly-named `wifiindicator.koplugin/` folder. Copy that into `koreader/plugins/` and restart.

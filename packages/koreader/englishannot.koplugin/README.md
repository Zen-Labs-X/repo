# EnglishAnnot — KOReader 英文单词中文标注插件

> 在 KOReader（Kindle / 安卓 ）上读英文书时，自动给生词叠加中文释义（仿 Kindle Word Wise），并在单词下方画一条下划线标识「这个中文对应哪个词」。支持按考试 / 难度选择词库，并可将 KOReader 自带的词汇本里的词自动标注中文。

## 功能

* 英文书页内自动识别生词，叠加中文释义（上方 / 下方可切换）

* 可选词库：常用全量 / GRE / CET4 / CET6 / TOEFL / IELTS

* 难度等级分级（越生僻越标，常用词默认不标）

* 词汇本联动：加入 KOReader 词汇本的词自动标注中文，**加入即标**，无需导出文件

* 下划线标识中文与单词的对应关系

# KOReader fonts

This directory caches the relaxed, KOReader-optimized font families published by
[nicoverbruggen/ebook-fonts](https://github.com/nicoverbruggen/ebook-fonts),
plus [Junicode](https://github.com/psb1558/Junicode-font). Each family has its
own folder containing metadata and an installable ZIP with only that family's
styles. The Junicode archive contains only `.ttf` files from its latest stable
release.

`ebook-fonts-all.zip` contains every cached `ebook-fonts` family under a
single `fonts/` directory, ready to unpack into a KOReader installation. It is
regenerated by the scheduled font scraper from the upstream release manifest
and its relaxed core and extra archives.

Each font package credits its upstream author; the font files retain their
upstream embedded copyright and license information.

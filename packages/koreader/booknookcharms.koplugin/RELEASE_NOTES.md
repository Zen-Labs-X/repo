# v1.1.0

Book Nook Charms V1.1.0

A sweeter, smoother little update for Book Nook Charms. ✨

This version polishes Charm Studio, adds easier day/night charm controls, improves favorites, and adds a few quiet compatibility touches for different KOReader devices.

What’s New

- Polished Charm Studio so resizing and placing charms feels cleaner and cuter.
- Added quick Charm Studio actions:
  - Set Day ☀
  - Save
  - Set Night ☾
  - Default
  - Reset
  - Cancel
- Added Quick Presets for Corner, Ribbon, and Tucked charm placement.
- Made charm sizing gentler with 0.1x size steps.
- Added a Tucked preset so ribbon charms and dog-ear charms feel smaller and softer with one touch.
- Added Troubleshooting ⚙ to check saved charm, default charm, book charm, day/night pair, and auto-pair status.
- Added Next Favorite Charm so you can cycle through your saved favorites.
- Added a Reader gesture action for Next Favorite Charm.
- Improved compatibility handling for Kindle and older Kobo KOReader builds.
- Updated the README with clearer setup, Charm Studio, gesture, compatibility, and troubleshooting notes.

Notes

Book Nook Charms is designed with Kobo + KOReader in mind, but may also work on other KOReader devices depending on the KOReader version.

If something does not work, please include your device model, KOReader version, what happened, and any helpful `crash.log` lines.

Happy reading, my lovelies. 📚✨

# v1.0.0

📖Book Nook Charms v1.0.0

A cozy KOReader plugin for decorating your reading screen with ribbon bookmarks, dog-ear corner charms, night charms, and black-and-white e-ink charms.

✏️Highlights

- Ribbon and dog-ear bookmark charms
- Night-friendly charm options
- Black-and-white e-ink charm set
- Charm Library and Charm Types menus
- Favorite Charms
- Charm Studio for size and placement
- Day/Night Pair mode
- Reader gesture actions
- Custom charm folder and starter templates
- Clean install folder: `booknookcharms.koplugin`

📦 Install

1. Download Book Nook Charms V1.0.0.zip.
2. Unzip it.
3. Copy booknookcharms.koplugin into .adds/koreader/plugins/
4. Restart Koreader
5. Open a book and look in the typsetting menu (Second menu at the top) for Book Nook Charms.

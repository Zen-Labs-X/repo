**New: Achievements**

- Over 80 global, all-time achievements across several themes (books finished, reading time, pages, daily/weekly streaks, single-day and single-session feats, time of day, reading pace and variety), each with its own icon.

- Opened from the reading-goal section's new "earned / total" cell (e.g. 42/82) or Tools → Reading insights → Show achievements (also assignable as a gesture).

- List with a progress header (Achievements 42/82 (51%)), earned items on top with unlock dates, locked ones below (greyed). Title-bar ☰ menu adds sort orders (by unlock time / name) and a filter (all / earned only / locked only).

- "New" ★ badge next to the count and on freshly-unlocked rows; cleared when you open the list.

- Background re-evaluation only when reading data actually changed; frequency is configurable (Once a day default, or Every open), and long-pressing the list's title bar re-scans everything immediately. Unlocked achievements persist and are never lost.

**Reading goal section reworked**

- The left cell now shows finished-vs-target as one figure (e.g. 18/30 "books finished"); the right cell shows achievements earned.

- Set the yearly target from the finished-books long-press menu (Set reading goal), now via a keyboard-friendly input dialog that no longer hides behind the popup or the keyboard.

- Removed the old Reading goal display (total/remaining) and Reading goal section show/hide settings.

**Uninstall cleanup**

Deleting the plugin with "Also delete plugin settings" now removes all of the plugin's own files and cache folder, every G_reader_settings key it wrote, and resets the sleep screen if it was set to Reading insights.

**Polish**

Tighter, consistent left/right padding in the book/achievement lists; fixed-width icon column so text lines up; the manually-added-books list drops its empty checkbox column.

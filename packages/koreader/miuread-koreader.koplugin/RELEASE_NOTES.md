# v5.6.7

- 改善书架分组和卡顿问题
- 重构扩展安装与下载恢复机制，修复下载卡死和残留状态；系统性优化 5.6 后的主页性能、后台调度、Reader 生命周期、休眠唤醒与低内存行为，并加强异常白屏和输入管道问题的诊断能力。
- 新增墨痕壁纸推荐，并修复 Beta 发布流程中的打包拦截问题；开发文档移出插件目录，发布检查可直接显示违规文件，确保后续 Beta Release 正常生成完整安装包。
- 重构下滑控制中心布局，恢复单行最多 8 个快捷项并统一 SVG 图标显示；优化快捷项自定义、设备能力过滤和状态展示，同时将觅阅自身更新入口重新收拢到设置中，减少界面割裂感。
- 5.8.0-beta.10：重构扩展包管理与下载系统，恢复可靠 fast path，并加入插件下载进度、断点续传、下载中心与休眠/网络恢复。
- 重构内置扩展市场下载安装内核，移除复杂线路评分、跨源断点和多套校验流程，改为固定顺序多源重试；只有 Size + SHA-256 校验通过后才认定下载成功，并统一使用 KOReader Archiver 校验与解压。新增同源断点、网络等待、事务安装、失败回滚、任务取消/清理与重启恢复，解决坏镜像、损坏 ZIP、任务卡死和安装中断等问题。
- 修复 KPW6 长期使用后持久化状态异常膨胀导致的严重卡顿，并增加低内存下载启动保护；补全 Kobo 休眠唤醒后的 Wi-Fi 恢复流程，在网络恢复期间暂停非必要联网后台任务，避免连接异常进一步拖慢主页。同步补充网络异常场景下的后台任务隔离与性能诊断，继续保留 5.8.0-beta.11 的扩展市场安装内核。
- 修复单章节进度同步与阅读时间阻塞问题
- 修复公众号入口与主页状态回归，完善阅读时间和进度同步稳定性，并优化 Kindle 低内存与网络恢复场景下的交互表现。

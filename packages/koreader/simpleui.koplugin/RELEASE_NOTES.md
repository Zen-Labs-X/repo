# 2.7.0

What's New in Simple UI v2.7.0

- Homescreen & Layouts: Added a new "Dashboard" homescreen preset and per-module column width (Bento Grid) options;
- Hardware Controls: Enabled the physical Home button to open the Simple UI Home Screen on all devices with a Home key;
- Reading Goals: Introduced new visual display rings for reading goals;
- Backup & Restore: Added a native backup and restore system;
- General bug fixes and quality-of-life optimizations.

# 2.6.0

What's New in Simple UI 2.6.0:

- Reading Heatmap: Added a new Reading Heatmap module.
- Customization: Introduced a browsable asset picker for easier selection and installation of icons and wallpapers.
- Clock: Added independent size controls for the clock face, date, and battery text.
- Cover Deck: Added a per-instance progress badge to the Cover Deck module.
- To Be Read: Added an option to automatically remove books from your TBR list once they are marked as finished.
- Quick Actions: Optimized and unified the behavior of Quick Actions across the interface. Fixed an issue where Custom Screen Quick Actions were missing from menus, and fixed a bug when tapping the bookmark browser.
- Bug Fixes: Fixed frame and background box misalignment with section labels across homescreen modules. Truncated the compact stats row to prevent layout stretching. Fixed cover scaling issues in the default layout, and ensured hidden collections remain visible in the Arrange screen.
- General bug fixes and quality-of-life optimizations.

# 2.5.0

What's New in Simple UI v2.5

- Custom Screens: Added support for creating extra Home-Screen-like pages, each with its own independent module layout, accessible from the Navigation Bar, Quick Actions, or Quick Settings Bar.
- Added two new Home Screen modules — Featured Collection (spotlight a single collection as a row of covers) and Flat Library (a single grid of every book, ignoring folder structure).
- Book Actions: Long-press (hold) on a cover is now supported directly on the Home Screen (Recent, To Be Read, New Books, Cover Deck, Currently Reading, Collections, and Featured Collection) opening the same book actions dialog previously only available from the Library file browser.
- Collections: Collections module now supports a configurable grid (up to 3 rows × 5 columns) and a new "Auto" cover style that switches between single-cover and 4-cover grid based on collection size.
- Recent Books / New Books: Both rows now let you choose 4 or 5 visible covers, and gained the same optional Pages/Series/New badges and Progress Style picker used elsewhere.
- To Be Read: No longer capped at 5 books. The list now paginates by swipe past that, gained an optional grid layout (up to 3 rows × 5 columns), and a new automatic Sort option (Title, Author, % Read, Shuffle) alongside manual Arrange.
- Clock: Added a new Analogue clock face style, alongside the existing Digital and Word styles.
- Reading Stats: Added three new selectable stat cards: Unread, Reading, and Abandoned.
- Library Browsing: Rewrote Browse by Author/Series/Tags for large libraries. Eliminates the freezes and slowdowns previously seen with thousands of books.
- Reading Stats: Corrected a discrepancy between the 7-day averages shown on the Home Screen cards and in the Reading Stats window.
- Collections Manager: Fixed an issue where selecting a collection from a book's long-press menu could leave the screen in a broken state.
- General bug fixes and quality-of-life optimizations.

# 2.1

What's New in Simple UI v2.1.0

- Streak & Freeze System: Track reading streaks via a calendar view and earn Freezes through reading milestones.
- New Quick Actions: Added "Recent" book switching grid, "Random" book opener, and custom "Group" action folders.
- Quote of the Day Upgrades: Support for custom quotes blended with book highlights, plus an optional fixed-height layout.
- Cover Deck: Simplified reorderable items and added support for Favorites and Collections.
- Icon Customization: Custom menu tab icons are now assignable via settings.
- Book Cover Transitions: Show full-screen covers when opening/closing books, with high-quality file reading and aspect ratio preservation.
- Reading Goals: Option to hide specific books from your goals directly from the finished books list.
- General bug fixes and quality-of-life optimizations.

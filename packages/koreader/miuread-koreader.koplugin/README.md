# 觅阅

**觅阅**是一款面向 KOReader 的微信读书助手，可在 Kindle、Kobo、Android 等运行 KOReader 的设备上浏览微信读书书架、生成本地 EPUB，并继续使用 KOReader 阅读。

当前正式版本：**3.0.0**

> 本项目为独立实现，与微信读书、腾讯及 KOReader 官方无隶属关系。

## 主要功能

- 扫码登录微信读书，浏览账号书架
- 生成纯净版或划线与想法版 EPUB
- 支持整本下载、按章节下载和后台下载
- 下载中断后保留进度，再次下载时继续
- 浏览和阅读微信公众号文章
- 同步阅读进度与阅读时间
- 搜索、筛选和管理已生成书籍
- 已生成的 EPUB 可作为本地书籍直接打开

## 安装

1. 下载 `miuread-v3.0.0-full.zip`。
2. 解压后得到 `miuread.koplugin` 文件夹。
3. 将该文件夹复制到 KOReader 的 `plugins` 目录。
4. 完整退出并重新启动 KOReader。

安装后的目录应为：

```text
koreader/
└── plugins/
    └── miuread.koplugin/
        ├── _meta.lua
        ├── main.lua
        └── miuread/
```

## 更新

新版可直接覆盖旧版插件文件，然后完整重启 KOReader。

正常更新不会要求重新登录，也不会删除已经生成的书籍、下载进度或本地阅读记录。

## 基本使用

### 登录

进入：

```text
KOReader → 插件 → 觅阅 → 扫码登录
```

使用微信扫码，并按页面提示完成登录。

### 生成书籍

进入「我的书架」，点击书籍后选择「生成／更新书籍」，再选择：

- **纯净版**：只保留书籍正文
- **划线与想法版**：在正文中显示可识别的划线与想法

不需要长按，也不需要单独执行修复操作。

### 后台下载

开始生成书籍时，可以选择留在当前页面，或转入后台下载。

后台下载只会在 KOReader 仍在运行时继续。KOReader 被关闭或系统停止进程后，下载会暂停；下次打开觅阅后可以继续。

### 微信公众号

在觅阅书架中进入「公众号」，可查看账号书架返回的公众号和文章。文章下载完成后会作为本地内容打开。

### 阅读同步

觅阅可以同步：

- 当前阅读进度
- 阅读时间

同步功能可在设置中分别开启或关闭。检测到本机与云端位置差异时，插件会先让用户选择，避免直接覆盖其他设备的阅读位置。

## 书籍与数据保护

- 新 EPUB 生成并检查完成后，才会替换旧文件。
- 生成失败时，原 EPUB 不会被覆盖。
- 网络中断、登录失效或 KOReader 被关闭时，已完成的下载进度会尽量保留。
- 删除插件不会自动删除已经生成到书籍目录中的 EPUB。
- 觅阅只处理当前账号有权阅读的内容，不提供未授权内容，也不绕过购买、会员或试读限制。

## 常见问题

### 更新后需要重新下载全部书籍吗？

不需要。已生成书籍可以继续阅读。只有需要更新正文、划线或想法时，才需要再次使用「生成／更新书籍」。

### 下载中途退出怎么办？

重新打开觅阅，在书籍页面继续生成。已保存的下载进度会继续使用。

### 为什么部分书籍只能生成试读版？

觅阅会遵循微信读书返回的阅读权限。未购买、会员已到期或本身只开放试读的书籍，只能读取相应范围。

### 为什么阅读进度没有立即同步？

常见原因包括网络未恢复、登录状态暂时失效，或本机与云端位置存在差异。可在「阅读同步」中查看状态并重新确认。

### 旧书中已经出现章节末尾的附加内容怎么办？

安装 3.0.0 后，在该书页面点击一次「生成／更新书籍」。新文件生成成功后会替换旧文件。

## 存储与清理

「存储与清理」中可以查看或清理：

- 下载断点与临时文件
- 未完成下载缓存
- 封面缓存
- 公众号文章缓存

清理前请阅读页面说明。划线、想法、已生成 EPUB 和账号数据不会因为普通缓存清理而一并删除。

## 问题反馈

反馈问题时，请至少提供：

```text
设备名称：Kindle Paperwhite 4
KOReader 版本：2026.07
觅阅版本：3.0.0
问题说明：简要说明发生了什么
已尝试：重启设备、重启 KOReader、重新登录等
```

请填写具体版本号，不要只写“最新版”。发生闪退时，可同时附上 KOReader 的 `crash.log`。

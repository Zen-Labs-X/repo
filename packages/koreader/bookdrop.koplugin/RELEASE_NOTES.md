# v1.0.0

The first public release of Bookdrop for KOReader.

Highlights:
- Browse and search Project Gutenberg, Standard Ebooks, textos.info, Gallica, Internet Archive, and Z-Library.
- Cover-first catalog with progressive loading, local cover caching, and separate cover downloads.
- Download EPUB, PDF, MOBI, DJVU, CBZ, and TXT files directly in KOReader.
- Filter by library, format, language, and content type, with sorting controls.
- Z-Library sign-in, resilient mirror selection, and automatic mirror fallback.
- Integrated manga browsing and reading powered by RakuYomi, with bundled popular sources.
- Configurable KOReader interface language from Bookdrop settings.
- Curated shelves that remain useful while catalogs are unavailable.

Installation:
1. Download Bookdrop-latest.zip below.
2. Extract it and copy bookdrop.koplugin into the KOReader plugins directory.
3. Restart KOReader and open Bookdrop from the main menu.

The device-specific manga runtime is downloaded on first use and is not included in this universal ZIP.

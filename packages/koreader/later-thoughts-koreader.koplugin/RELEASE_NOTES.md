# v0.6.1

First public release of Later Thoughts.

Later Thoughts is a minimal, book-independent notes plugin for KOReader.

Highlights:
- Named plain-text notes
- Quick Entry
- Manage Notes
- Notes sorted by most recently modified
- Timestamp, date, book/page, divider, and bullet quick inserts
- Tap-outside dismissal for the Insert menu
- Kindle keyboard-safe note entry
- Tested with KOReader + ZenUI on Kindle

Installation:
1. Download `later-thoughts-v0.6.1.zip`
2. Extract it
3. Copy the entire `later_thoughts.koplugin` folder into `koreader/plugins/`
4. Fully exit and relaunch KOReader

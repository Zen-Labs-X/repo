This is the first release of the **Page Scrubber** plugin for KOReader!  

### ✨ Key Features
* **Split View Layout:** A beautiful, newly designed layout featuring a page preview card on the left and an interactive menu on the right.
* **Unified Annotations Tab:** Easily browse, sort, and navigate through your Bookmarks, Highlights, and Notes all from the same menu.
* **Robust UI Scaling:** Built with a rock-solid, dynamic mathematical layout. The interface automatically adapts its margins and dimensions to fit any UI scale perfectly without crashing or overlapping.
* **Smart Highlight Filters:** Dynamic toggle folders for different highlight types (underline, invert, etc.) that mathematically adapt to your available screen space.
* **Quick Navigation:** Jump through chapters, flip through annotations, and toggle bookmarks seamlessly with a fixed bottom-row control.

### 🛠️ Installation
1. Download the source code or the folder directly.
2. Extract the `page_scrubber.koplugin` folder.
3. Place it inside your KOReader plugins directory (usually `koreader/plugins/`).
4. Restart KOReader and enjoy!

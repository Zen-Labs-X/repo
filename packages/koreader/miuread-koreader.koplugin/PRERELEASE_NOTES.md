3.1.0-beta.2 内测版

本版沿用 3.1.0-beta.1 的觅阅首页预览，并明确固定为内测更新通道。

更新内容

1. 更新通道明确显示为“内测通道”，不再使用容易混淆的简写。
2. 检查更新固定读取 beta 分支的 update-beta.json。
3. 只接受 channel=beta 的更新清单和内测全量包，拒绝误装正式通道更新。
4. GitHub Release 工作流会在 beta 标签下生成 update-beta.json。
5. 保留觅阅首页预览、本地书籍区域和原生界面备用入口。

说明

- 本包是内测通道源码包。
- 安装后，更新设置中应显示“更新通道 · 内测通道”。
- 不会自动切换到正式通道。

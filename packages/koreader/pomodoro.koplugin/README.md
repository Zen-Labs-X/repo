# Pomodoro Timer for KoReader

</center>

This is a minimal pomodoro timer plugin for KoReader.

It has a 25min focus session followed by a 5 minute break on a cycle.

In order to preserve battery life and reduce screen updates, it uses a 5-stage progress bar to display the progress through the session. If your Kindle is sleeping but the timer is still running, it flashes the lock screen when it switches between focus and break sessions. It does not run in the background whilst you read on KOReader, it runs whilst its open, as it's intended to be used as a deskside timer.

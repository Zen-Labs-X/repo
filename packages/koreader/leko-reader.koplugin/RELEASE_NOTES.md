# v0.16.0

## 0.16.0

### 书源兼容与性能

- 提升书源兼容性，尝试性支持部分高级书源。
- 提升搜索、加载和检查更新的性能。
- 改善响应较慢的书源搜索超时问题。
- 改善封面加载与换源的稳定性。

### 阅读与界面

- 改善中文行宽与长章节排版，修复长段落、空白尾段和跨章边界造成的空白页问题。
- 修复正文左右留白不均，以及部分页边距挡位效果重复的问题。
- 页眉增加时间显示，章节首页也能查看时间。
- 缩小页眉、页脚字号，减少排版占用。
- 对支持的设备增加阅读灯调节选项。
- 优化阅读界面的操作范围，扩大“下一页”的触发区域。
- 接入 KOReader 阅读统计，可在统计界面查看阅读进展。

# v0.15.49

# 更新日志

## 0.15.49

- 精确保存并恢复章节内阅读位置，减少退出、重排版和换源后的跳读。
- 修复缓存进度条在排版、跳转等弹窗关闭后消失的问题。
- 补齐 Kindle 实体翻页键映射。
- 优化换源后的返回与续读流程，直接回到当前章节。
- 优化手动优先书源的搜索调度与超时重试顺序。
- 修复已有阅读器中从书籍详情点击“继续阅读”可能导致 KOReader 闪退的问题。

# v0.15.47

- 新增“动画效果”，默认开启。
- 新增可选的“跨章净屏动画”，默认关闭，可在阅读排版菜单中单独开启。
- 页脚现在显示“当前章 / 总章数”和本章阅读百分比。
- 邻章缓存进行时，页脚会临时显示缓存数量和进度条。

# v0.15.39

## 更新内容

- 支持字体自定义，可在阅读排版中选择 KOReader 已安装的字体；同名字体可按实际文件位置选择。
- 可能修复部分书籍导出后没有封面的问题。
- 可能修复部分书源缓存到最后一章时失败的问题。

# v0.15.38

本版优化了 Leko 菜单与存储页面的响应速度。

- 主菜单立即显示上次缓存的容量与书源数量
- 菜单出现后在后台刷新统计，不再阻塞点击
- 存储页面复用一次扫描结果，避免重复遍历缓存目录
- 前台阅读、搜索等任务可优先于后台统计

安装：解压后将 leko.koplugin 文件夹放入 KOReader 的 plugins 文件夹，并完全重启 KOReader。

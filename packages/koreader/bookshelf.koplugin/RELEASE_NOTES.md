**New**

- Select all books in a shelf, from the bulk menu or a gesture - the way to select a chip built from filters, which has no folder to long-press (#320)
- Each catalogue chip can choose where its downloads are saved: long-press the chip and use **Saves to** (#319)
- Catalogue downloads now cover every format KOReader can open, including AZW3, CBZ and CBR
- **Uppercase labels** toggle for chip labels, under Bookshelf chips

**Fixes**

- "Check for updates" now always checks for a release. It could previously install a configured development branch instead, if one had ever been set

First release.

Word Wise for KOReader — short definitions above difficult words, drawn as a per-page overlay on the original book (no copy, no file rewrite). Adjustable difficulty level. Ships with a built-in ~30k-word open dictionary, so it works out of the box; drop your own database into the `wordwise/` data dir to override it. On Kindle, the device's own Word Wise corpus is auto-detected.

### Install
Download `wordwise.koplugin.zip` below and unzip it — it expands to a correctly-named `wordwise.koplugin/` folder. Copy that into KOReader's `plugins/` directory and restart. See the README for per-device paths.
